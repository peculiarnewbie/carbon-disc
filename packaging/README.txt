Carbon Disc — yet another FFmpeg wrapper (early development)

Quick start
  Extract anywhere and run carbon-disc (or carbon-disc.exe). FFmpeg ships
  beside the app, so nothing else is needed.

  macOS: this build is not code-signed, so the first time you open it,
  right-click carbon-disc and choose Open. It is an x86_64 build and runs
  natively on Intel Macs and through Rosetta on Apple Silicon.

  To build from source or report issues:
  https://github.com/peculiarnewbie/carbon-disc

Bundled software
  FFmpeg (GPL-2.0-or-later) is included — see THIRD-PARTY-NOTICES.md and
  COPYING.GPL-2.0 beside this file.
