Carbon Disc — yet another FFmpeg wrapper (early development)

Quick start
  Extract anywhere and run carbon-disc (or carbon-disc.exe).

  This is the slim download: it does NOT include FFmpeg. Carbon Disc needs
  the ffmpeg and ffprobe commands, and if they are missing it opens a
  setup screen with per-platform install instructions (winget, Homebrew,
  or your Linux package manager).

  To build from source or report issues:
  https://github.com/peculiarnewbie/carbon-disc
